# Offshore Platform — Muse production handoff

**Status: preproduction package ready; video not generated.** The user will give the prompt to Muse, which is expected to produce images, video and audio. This package does not claim that Muse has been run or that its current export capabilities were verified.

Recommended video: **How Do You Build Something This Big in the Ocean?** A US-English visual engineering explainer, landscape 16:9, intended 720p/24 fps, approximately 4–5 minutes. Follows a generic fixed steel-jacket platform from shore fabrication through transport, foundation and topside installation; briefly compares a floating semi-submersible.

## Use in Muse

1. Open [MUSE-MASTER-PROMPT.txt](MUSE-MASTER-PROMPT.txt), copy its entire contents and paste into Muse. It includes the full narration and all 60 planned shots; no repository access is required.
2. Alternatively download [muse-production-pack.zip](muse-production-pack.zip), extract and attach the master prompt and accompanying documents if Muse supports document attachments.
3. Ask Muse to produce and export the assets, then inspect the actual result. Export settings and capability limits must be reported honestly. No YouTube publication is authorized.
